# Vortex Project Note

The runnable implementation in this repository is VortexHash v1 under
`hash_functions_core/Vortex/`. It provides training, model selection,
generated-code emission, and evaluation tools for learned vector placement.

Implementation details and user workflows live in
`hash_functions_core/Vortex/README.md` and the public workflow docs.
